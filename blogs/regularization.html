Introduction

Regularization appears in different fields, and act as the same role to provide prior information when the problem is ill-posed, i.e., has infinite number of solutions, such that the size of solution set is reduced.

In machine learning and inverse problems

Linear case - linear regression

The mathematical structure is the same structure. $n$ = # features = # parameters to to find. In a linear model, this is equal to the number of pixels $N \times N$. If the matrix $X$ does not have full column rank, which is typically a fat matrix, the problem is ill-posed. For a linear model we can go back to check which features are independent, so as to reduce the #features, and thereby reduce #parameters. In a neural network model, $n$ can be much larger than $N \times N$, and almost always gives a ill-posed problem.

Nonlinear case - neural networks

The parameters (including weights and biases) in a neural network is massive, and way more then the data points we have. The solution is therefore not determined. The number of solutions is infinite. A fundamental question in neural network is that why gradient descent is able to pick the solution that generalizes well. And also neural network tends to pick smooth functions (lower-order functions).

In optimal transport

The standard optimal transport problem is a convex optimization problem with a linear objective, which is convex but not strictly convex. Consequently, the optimal transport plan is not necessarily unique. Introducing positive entropy regularization makes the objective strictly convex, thereby makes the solution unique. (Actually it is not just strictly convex but also $\epsilon$-strongly convex.)

If the original OT problem has multiple optimal solutions, entropic regularization selects the one with maximum entropy among those solutions.

Besides this entropic prior information, this entropic regularization also offer computational advantage that leads to the efficient Sinkhorn algorithm.
